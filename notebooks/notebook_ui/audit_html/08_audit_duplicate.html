STEP 08

Exact Duplicate Text Analysis

Identifying texts that appear more than once without any difference in the dataset.

The back side explains the difference between duplicate groups and extra duplicate rows.

Difference Between Two Important Metrics

Exact duplicate groups

Number of unique texts that appear more than once.

Extra duplicate rows

Number of additional rows after keeping one instance of each text.

Example: A A A B B

Duplicate Groups

Texts A and B are repeated; therefore, the number of duplicate groups is 2.

Extra Rows

For A, two extra rows exist and for B, one extra row exists. The total number of extra rows is 3.
