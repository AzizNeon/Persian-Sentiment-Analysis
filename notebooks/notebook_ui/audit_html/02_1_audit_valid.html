Dataset Structure Validation

Checking required columns and validating sentiment labels

The back side explains why this validation is required before analysis.

Why Is This Validation Necessary?

Label Validation

The class distribution code expects the five valid sentiment classes. Invalid labels such as 3 or -3 should be detected before further analysis.

Structure Validation

The existence of required columns is checked to ensure that later stages do not run on incomplete or incorrect data.

row_count Dataset row count is stored for final integrity checks.
dataset_fingerprint Dataset fingerprint is recorded to detect unexpected changes.
