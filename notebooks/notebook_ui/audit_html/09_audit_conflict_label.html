Conflicting Label Analysis

Identifying identical texts that are assigned to more than one sentiment label.

The back side explains why these inconsistencies are important.

Why Is This Important?

Model Learning Issue

If exactly the same sentence exists with different labels, the model cannot learn a consistent relationship between text and label.

Conflict Example

The same text is recorded with two different labels: label = 1 and label = 2
