STEP 04

Prepare Features and Target

The text column is used as the input feature and the sentiment column is separated as the target variable.

The back side explains how class imbalance is handled.

Model Input and Output

X

Contains normalized texts that are later converted into numerical features using TF-IDF.

y

Contains the five sentiment labels from -2 to 2.

Despite class imbalance, no resampling is applied at this stage. The data is first divided into training and test sets using stratification.
