STEP 15

Cross-Validation and Final Model Selection

Candidate models are evaluated using cross-validation to obtain more reliable performance estimates.

The back side explains why cross-validation is used before final model selection.

Why Use Cross-Validation?

More Reliable Evaluation

Performance is measured across multiple data splits instead of relying on a single train-test division.

Reduce Split Dependency

The evaluation becomes less sensitive to the specific samples included in one test set.

Macro F1

The main selection metric because it treats all sentiment classes equally.

Final Candidate

The model with the strongest validation performance is selected for final saving and error analysis.

Cross-validation provides a more stable estimate of model performance before choosing the final classic machine learning model.
