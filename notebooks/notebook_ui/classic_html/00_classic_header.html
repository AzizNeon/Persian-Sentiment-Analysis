03 — Classic Machine Learning Models for SentiPers

Notebook Objective

In this notebook, the cleaned SentiPers dataset is converted into numerical features using TF-IDF, and several classic machine learning models are trained for sentiment classification.

The data is first divided into training and test sets. Then, all text transformation and model training steps are performed inside a Pipeline to prevent information leakage from the test set.

The main stages of this notebook include:

  • Loading and validating the cleaned dataset
  • Stratified train-test split
  • Text feature extraction using TF-IDF
  • Training baseline and classic machine learning models
  • Comparing models using multiclass evaluation metrics
  • Analyzing confusion matrices and prediction errors
  • Cross-validation and selecting the best classic model
  • Saving models, result tables, and final plots

The result of this notebook is used as a Baseline for comparison with ParsBERT in the next notebook.
