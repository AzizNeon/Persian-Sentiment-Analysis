STEP 16

Error Analysis

Incorrect predictions of the selected model are inspected to understand model weaknesses and common error patterns.

The back side explains the purpose of analyzing prediction errors.

Why Analyze Errors?

Wrong Predictions

Samples where the predicted label differs from the actual label are extracted for further inspection.

Confusing Classes

Similar sentiment classes that are frequently confused by the model can be identified.

Model Limitation

Error patterns help reveal limitations of classical models compared with transformer-based approaches.

Future Improvement

Observed errors can guide future preprocessing and modeling decisions.

Error analysis provides qualitative insights that cannot be obtained from evaluation metrics alone.
