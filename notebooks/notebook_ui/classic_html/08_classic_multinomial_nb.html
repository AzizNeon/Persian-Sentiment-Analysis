STEP 08

Train Multinomial Naive Bayes Model

The first real sentiment classification model is trained and evaluated using TF-IDF features and the Naive Bayes algorithm.

The back side explains Pipeline structure and smoothing parameters.

How Is the Model Built?

TF-IDF

Training texts are converted into non-negative numerical vectors so the model can learn word and phrase importance.

MultinomialNB

The probability of each sentiment class is calculated based on textual features.

alpha=1.0

Laplace smoothing prevents zero probabilities for features that are not observed in some classes.

Pipeline

Text transformation and classifier training are combined into one workflow to prevent test data leakage.

Due to class imbalance, Macro F1 is emphasized for evaluation and Accuracy alone is not sufficient for decision-making.
