STEP 07

Build and Evaluate Baseline Model

A simple non-learning model is created to define the minimum expected performance for real models.

The back side explains the role of the baseline model and why TF-IDF is not used.

What Does the Baseline Model Do?

most_frequent

The model predicts the most frequent label from the training data for all test samples.

Comparison Metric

Real models should achieve better performance than this baseline, especially in Macro F1.

The baseline model does not use TF-IDF because it does not learn from text and only provides a simple reference point for model comparison.
