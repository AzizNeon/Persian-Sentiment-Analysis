Train-Test Split

The dataset is divided into training and test sets while preserving the class distribution.

The back side explains the role of stratified splitting and test data.

Why Use Stratified Splitting?

Training Set

Contains 80% of the data and is used for learning TF-IDF representations and training models.

Test Set

Contains 20% of the data and is only used for final evaluation of trained models.

The parameter stratify=y preserves sentiment class ratios in both sets, and random_state keeps the split reproducible.
