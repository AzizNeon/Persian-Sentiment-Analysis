STEP 09

Train Logistic Regression Model

Logistic Regression is trained and evaluated using TF-IDF features and balanced class weighting.

The back side explains regularization, class weights, and solver settings.

Main Model Settings

class_weight="balanced"

Errors from minority classes receive higher weights during training to reduce the effect of dominant classes.

C=1.0

Controls regularization strength. A smaller value means stronger regularization.

penalty="l2"

Prevents feature weights from becoming excessively large and reduces overfitting risk.

solver="saga"

An optimization algorithm suitable for large sparse TF-IDF feature spaces.

The model is trained only on X_train and X_test is used only for final evaluation.
