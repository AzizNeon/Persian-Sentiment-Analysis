STEP 12

Initial Classic Model Comparison

All trained models are compared and ranked using common evaluation metrics.

The back side explains the main ranking metric and baseline role.

How Are Models Compared?

Macro F1

The main ranking metric because all classes are considered with equal importance.

Weighted F1

Shows overall model performance based on the actual number of samples in each class.

Baseline Model

Real model results are compared with Dummy Classifier to measure actual learning ability.

Temporary Ranking

Current ranking is based on the test set and final selection is performed after cross-validation.

Higher Accuracy alone is not sufficient. A suitable model should also perform well on minority classes.
