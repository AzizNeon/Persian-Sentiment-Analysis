Train Linear SVM Model

Linear Support Vector Machine is trained and evaluated using TF-IDF features and balanced class weighting.

The back side explains decision boundaries, margins, and main settings.

How Does Linear SVM Work?

Decision Boundary

The model creates linear boundaries in the TF-IDF feature space to separate sentiment classes.

Margin Maximization

The model attempts to increase the distance between samples close to the decision boundary for more stable classification.

C=1.0

Controls the balance between a wider decision margin and penalties for misclassified samples.

class_weight="balanced"

Minority class errors receive higher weights to reduce the impact of dominant classes.

The LinearSVC model does not directly generate class probabilities; however, it usually performs well on high-dimensional text data.
