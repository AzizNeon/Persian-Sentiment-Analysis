STEP 06

Define TF-IDF Feature Extraction

Configuration of converting Persian texts into numerical vectors for classic machine learning models.

The back side explains data leakage prevention and TF-IDF settings.

Main Feature Extraction Settings

ngram_range=(1, 2)

In addition to single words, two consecutive words are also considered as features.

min_df=2

Features appearing in only one document are removed to reduce vocabulary noise.

sublinear_tf=True

The effect of very frequent words is controlled using logarithmic scaling.

stop_words=None

Stop words are not removed because words such as not and does not can change sentiment direction.

TF-IDF is placed inside a Pipeline so that it is fitted only on training data at each stage and test information does not enter the learning process.
