STEP 14

Confusion Matrix Analysis

Confusion matrices are generated to analyze prediction patterns and class-level errors.

The back side explains how confusion matrices reveal model behavior.

What Does a Confusion Matrix Show?

Correct Predictions

Values on the main diagonal represent samples correctly classified by the model.

Classification Errors

Off-diagonal values show which sentiment classes are confused with each other.

Class Difficulty

Classes with lower diagonal values are more difficult for the model to identify correctly.

Model Comparison

Different models can be compared based on their error patterns, not only their final scores.

Confusion matrices provide a deeper view of model performance by showing where classification mistakes occur.
