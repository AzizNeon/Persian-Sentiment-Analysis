STEP 13

Classification Reports by Class

Precision, Recall, and F1 metrics are calculated and compared separately for each sentiment class.

The back side explains why individual class analysis is important.

Why Are Class-Level Reports Important?

Precision

Shows how many samples assigned to a class by the model actually belong to that class.

Recall

Shows how many actual samples of each class were successfully detected by the model.

F1-score

The harmonic mean of Precision and Recall, showing the balance between these two metrics.

Support

Displays the number of real samples belonging to each class in the test set.

At this stage, Dummy Classifier is excluded because it always predicts the dominant class and does not provide additional analytical value.
