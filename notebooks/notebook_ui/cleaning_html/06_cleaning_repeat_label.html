STEP 06

Remove Same-Label Duplicates

Extra copies of normalized identical texts with the same sentiment label are removed.

The back side explains the difference between duplicate and conflicting label cases.

What Happens in This Stage?

Same-Label Duplicate

When the same text appears multiple times with the same label, one copy is kept and extra copies are removed.

Conflicting Label

If the same text appears with different labels, no row is removed at this stage.

Removed rows are stored in removed_same_label_duplicates for review and reporting.
