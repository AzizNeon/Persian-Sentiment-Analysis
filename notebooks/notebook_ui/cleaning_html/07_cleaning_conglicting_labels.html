STEP 07

Remove Conflicting Label Groups

Text groups assigned with multiple sentiment labels are identified and removed from the cleaned dataset.

The back side explains why these samples are removed instead of fixed.

Why Remove These Samples?

Label Ambiguity

The same text cannot provide a consistent training signal when it has multiple different sentiment labels.

No Arbitrary Correction

No label is selected manually because choosing one label would introduce an unsupported assumption.

Removed groups are stored in removed_conflicting_labels for complete cleaning reports.
