Comparative Error Analysis of Two Models

ParsBERT and Linear SVM errors are analyzed class-by-class and sample-by-sample on the shared Test Set.

Hover over the card to view the details.

Comparative Error Analysis

The goal of this stage is identifying the source of performance differences without changing models, data, or Hyperparameters.

Per-Class F1

Precision, Recall, and F1 values of each class are compared between models.

Paired Errors

Samples where only one of the two models predicts correctly are analyzed.

Disagreements

Prediction disagreement patterns and error directions are extracted.

Significance

Accuracy differences are analyzed using the paired McNemar test.

These results are only used for post-evaluation analysis and are not used for model adjustment.
