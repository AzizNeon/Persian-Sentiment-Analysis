Why Is Runtime Estimation Important?

The successful Smoke Test showed that ParsBERT training is possible on CPU, but each training step requires considerable time. Therefore, the real computational cost must be estimated before starting the complete Fine-tuning process.

Smoke Test with Batch Size = 1 required approximately 28 sec / step.
