What Happens in This Stage?

The pretrained ParsBERT weights are loaded and a five-output classification layer is added on top of the model. Then, real samples are used to verify that the model can generate Logit, Probability, and Loss without errors.

This stage only validates the architecture. No model weights are fine-tuned yet.
