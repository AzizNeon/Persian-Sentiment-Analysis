Stratified Dataset Split

Training, validation, and test sets are created while preserving the original sentiment class distribution.

Why Stratified Split?

Stratification ensures that all dataset splits maintain similar proportions of the five sentiment classes.

Train Set

Used for updating model weights during Fine-tuning.

Validation Set

Used for monitoring training progress and selecting the best checkpoint.

Test Set

Reserved for final evaluation after training is complete.

The same test set is later used for comparison with classic models.
